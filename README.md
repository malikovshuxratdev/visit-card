# Visit Card Generator

A modern web application for generating personalized visit cards with camera integration.

## Features

-   **Authentication System**: Secure login with username and password
-   **Camera Integration**: Capture photos using device camera
-   **Card Generation**: Create personalized visit cards
-   **Print Preview**: Preview cards before printing
-   **Responsive Design**: Works on desktop and mobile devices

## Getting Started

1. Install dependencies:

    ```bash
    npm install
    ```

2. Start the development server:

    ```bash
    npm run dev
    ```

3. Open your browser and navigate to the application URL
4. Login with the provided credentials
5. Start generating your visit cards!

## How to Use

1. **Login**: Enter your username and password on the login page
2. **Home Page**: View the card preview and instructions
3. **Camera**: Take a photo using your device camera
4. **Generator**: View and customize your generated card
5. **Print**: Preview and print your final card
